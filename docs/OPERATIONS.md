# 运维说明

## 当前部署

- 正式地址：https://wyd-meal-reservation.online
- 部署平台：站点所有者自己的 Cloudflare Workers 与 D1。
- 网站路由：`wyd-meal-reservation.online/*`，见 `wrangler.json`。
- 用餐自动结算：每小时执行一次，已配置在 Cron Triggers 中。

根域名 A 记录必须保持 Proxied（橙云），以触发 Worker 路由。`rsend`、`send` 两条发信 CNAME 保持 DNS only（灰云），DKIM和DMARC保留。不要重新导入将根域 A 记录改为灰云的迁移前备份。

生产服务密钥通过 Cloudflare Secrets 管理，GitHub上传不会自动触发部署。代码更新与生产发布是独立操作。

## 备份与迁移

在结构迁移或数据调整前备份 D1，并将备份存放在仓库以外。备份含有用户资料和密码哈希，不应作为 GitHub 附件或发布包上传。

迁移时保留用户ID、密码哈希及预约、额度、通知等关联关系；排除旧会话与验证码。头像在 `avatars` 表中，需要随业务数据库一并迁移。旧 Sites 应用及数据库仅作历史备份，切换后不再与新站同步。

## 验证范围

现有部署曾通过首页、页面资源、原密码登录、王亦达邮箱绑定限制、管理员首次修改密码限制、高德附近搜索及新数据库会话识别验证，HTTP会跳转到HTTPS。

邮箱配置存在不等同于实际邮件送达成功，应通过真实注册或绑定流程确认。自动完成逻辑已在本地 Workerd/D1 验证，线上定时日志和长期免费额度仍需观察。当前网络曾验证直连成功，不能保证所有地区和运营商的访问效果。

旧 ChatGPT 任务“每小时完成到期的放纵餐预约”可在任务管理中关闭，新站不依赖该任务。
